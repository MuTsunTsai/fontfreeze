FontFreeze

FontFreeze is a free, open-source online tool that freezes OpenType features and variations into a font. It creates a customized copy of a font with the features you choose permanently turned on or off, so you can use exactly the font you want in apps that don't support font feature settings, such as Visual Studio, Microsoft Word, many terminals, games and older software.

What you can do with it

  • Permanently enable stylistic sets (ss01–ss20), character variants (cv01–cv99), slashed zero (zero), old-style figures (onum) and other OpenType features.
  • Permanently disable ligatures (calt, liga) in coding fonts.
  • Turn a variable font into a static font at any weight, width or other axis value.
  • Subset fonts by removing glyphs or keeping only the glyphs you need.
  • Rename the font family, adjust line height and letter spacing, and export to TTF or WOFF2.
  • Everything runs in your browser using fonttools and Pyodide; your font files are never uploaded.

How to use it

  1. Open a font file (or drop it onto the page, or pick an installed font).
  2. Choose a variable instance or set each axis, and check the features you want to activate or deactivate.
  3. Preview the result, then click "Generate font!" and install the downloaded font.

Source code and documentation: github.com/MuTsunTsai/fontfreeze
